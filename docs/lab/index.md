# Lab

Lab은 아직 표준 패턴으로 굳지 않았지만 Web3의 다음 적용면을 넓힐 수 있는 실험 주제를 다룬다. 각 글은 아이디어 소개보다 `가설`, `가능한 구조`, `검증 질문`, `리스크`를 중심으로 읽는다.

## 현재 추적하는 실험 축

- AI 에이전트가 지갑, 권한, 결제, 기록을 다루는 구조
- 민감 데이터 공개 없이 자격과 사실을 증명하는 ZK/VC 조합
- RWA, 오프체인 데이터, 감사 증명을 연결하는 검증 파이프라인
- 사람, 조직, 에이전트의 행동을 나중에 검증 가능한 기록으로 남기는 방식
